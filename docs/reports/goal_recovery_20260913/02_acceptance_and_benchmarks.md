# 不再缩减的最终验收与已知装置基准

本文件是后续实施建议的父目标清单。子任务可以很小，父目标必须完整保留。实现时将每条映射到生产入口、真实输入、证据文件、检查器及具体执行结果；不得把“存在文件/定义合同/执行过/回报 fail”直接计为满足最终物理门。

## 1. 两本账和三个成功概念

维护能力账与候选证据账，分别回答“系统会不会做”和“这个候选究竟通过了什么”。软件回归成功、已知装置基准成功、原创净输出候选成功分别计数，不相互替代。

| ID | 最终要求 | 必需验收 | 当前快照 |
|---|---|---|---|
| R01 | 同一通用生产链处理已知和新候选 | 身份/单位/适用性一致；移除 display/family/benchmark 标签后路由及物理判定不变 | 部分基础具备 |
| R02 | ITER 等装置可表示并可真正反解 | 描述往返、隐藏参数恢复、多初值、可识别性与独立留出预测分别通过 | 未具备完整路径 |
| R03 | 物理方程和空间/时间求解可信 | 完整适用守恒/边界/闭合，独立残差与导数、解恢复、网格/时间收敛、稳定性/损失/输运/燃烧 | 当前静态四案失败 |
| R04 | 工程与控制覆盖整机任务 | 实际线圈/电路、热/结构/材料/环境、故障、启动停机、外部供能与回流、适用燃料循环 | 仅拾取子系统 |
| R05 | 全装置净能量/净电成立 | 冻结系统边界及周期；无漏项、无重复计能；不确定性与模型差异下仍有正净输出证据 | 无完整 producer |
| R06 | 独立物理验证与 UQ | 独立数据来源、校准/验证隔离、误差与适用域、模型差异、可追溯传播 | validation 未执行 |
| R07 | 高等级证据与最终 authority 可达 | 真实合格 evidence 能晋升；screen/missing/cross-boundary/replay 不能冒充 | 当前固定筛选上限 |
| R08 | 三 Genome 开放式发现闭环 | 真实后代→物理求解→档案回写→后续提议；多机制/几何/实现变化可达；失败可恢复 | 队列不等于生成器 |
| R09 | 原创性有独立支撑 | 数学等价/结构/行为/机制差异与文献专利检索，披露日期和覆盖范围 | 未具备完整路径 |
| R10 | 可复现交付与原始目标关账 | 新鲜干净环境/工作区重放，代码与数据版本、全部门证据及审查；至少一个同时通过 R03–R09 的新候选 | 未完成 |

R10 不能由“R01–R09 的软件实现存在”代替。若完整平台已实现而未找到候选，记录 `platform_ready=true`、`discovery_goal_achieved=false`。若缺外部证据，不改变 R06/R07，记录缺口及获取动作。

## 2. ITER 的正确角色

ITER 是科学与工程设计参考，不能作为已测得全装置正净电的成熟电站。ITER 官方说明其设计目标是等离子体 500 MW 聚变功率、50 MW 注入加热、Q=10，并明确不生产电力；这些是设计目标，不能填入实验 validation 表。[ITER 官方 FAQ](https://www.iter.org/faqs)。

因此“现有装置可以通过测试”应解释为：**通过自己适用的表示、反解和物理基准；完整重现它已知的能力与局限。** 不能要求 ITER 通过新电站的净电正例门，也不能因为其名字而豁免方程、数据或数值检查。

每个 reference 的 mission 必须从来源、装置功能和声明推导。新候选的净输出 mission 单独冻结，禁止把 reference 的较小任务复制给新候选来降低门槛。`not_applicable` 必须有基于物理任务和组件的证明，不能由 `name==ITER` 触发。

至少设置三种基准角色：

| 基准角色 | 用途 | 可用证据边界 |
|---|---|---|
| ITER 公开设计基准 | 几何/线圈/平衡/设计状态的编码和重构；发现不适用筛选 | 设计一致性、有限 code-to-code；不是其未来运行的实验验证 |
| 有公开诊断数据的实际放电/实验基准 | 真反演与留出预测；检验模型差异和实测不确定度 | 只覆盖数据对应工况；装置与具体数据集须先核实授权、版本和适用性 |
| 与首个基准具有不同 capability 需求的第二基准 | 防止仅支持单一拓扑；验证 capability 路由与拓扑扩展 | 可考察三维磁约束或开放损失实验；必须取得实际可用数据后才登记为可执行基准 |

第二、第三类的具体装置/shot/数据文件尚未在本轮取得，因此状态是待获取，不预先承诺某个装置已可复现。旧版 ITER/C-2W anchor 可以帮助定位字段和负例，不能直接变成新 validation 数据。

## 3. “反解”拆成四个互不冒充的测试

**B0：表示往返。** 从源数据编码 G1/G2/G3，再导出与源相同的几何、组件、状态及单位。输出缺失字段和可表示误差。哈希往返只验证序列化，不能替代物理往返。

**B1：数值反演。** 明确可识别的未知参数/边界/线圈电流等向量 θ、已知输入、观测 y 和测量误差。由同一生产正向算子 F(θ) 构成残差，求解 θ；所有先验、正则化、约束及可识别性分析事前登记。不得把隐藏答案放进初始化、搜索边界的极窄中心、生成器模板或 solver cache。多个明显不同初值与噪声/缺测组合要有实际运行。

**B2：留出前向预测。** 拟合只能用 calibration 数据。verification 数据和 validation 数据都单独登记；验证观测不得进入 profile、source、边界或调参。留出可按观测通道、工况、放电或来源划分；一个给定的压力 profile 不允许再拿来当同源预测成功。报告逐项带量纲误差、预测区间/覆盖及适用域。

**B3：从 grammar 可达的恢复。** 测试搜索语言能否生成足以表示参考装置的结构，不只是导入一个答案。盲隐藏部分结构/参数，使用可复现 seed 和公开约束进行有界搜索，输出找到/未找到、覆盖与预算。允许物理等价或不可辨识解集合，不能要求从有限观测恢复唯一整个装置，也不能以非唯一为由跳过误差报告。

正例验收容差必须在看待验结果前由数据精度、模型误差预算及工程需求制定。来源不足时门为 `pending_data`，不能临时填一个宽松阈值。测试必须包含下列负例：

- 标签删除、顺序打乱、候选/工况/单位错配和重复收据。
- 训练/验证数据泄漏、以输入重现充当预测、把 ITER 设计目标当测量。
- 输入矛盾、域外模型、不可识别参数；明确报告对应原因。
- reference 绕行：普通候选与 reference 在相同 mission/输入下结果必须一致。
- 非发电装置不能晋升为净电正例；必要负载缺失不能按零计算。

## 4. 全装置净输出的账本

沿用项目对 plant power / 净电的要求，默认主指标为周期平均站级净电，同时单列聚变释能、可用热和系统总能量平衡。若用户最终明确要求另一种有用能输出形式，必须显式更改 mission 并新建版本；不得为了 pass 从净电偷换成等离子体 Q 或热功率。

```text
Q_plasma = P_fusion / P_aux_injected                 # 不是站级净电
P_net,e = P_gross,e - Σ P_aux,e - P_other_losses,e
E_net,e = ∫cycle P_net,e(t) dt
P_average,net,e = E_net,e / T_cycle
```

系统边界至少覆盖加热/电流驱动墙插功率、磁体及电源损耗、低温、真空、泵与冷却、燃料制备/处理、控制、转换和储能往返损失；按候选实际组件列出适用项。采用直接能量转换的候选用对应能量路径和效率依据，不能机械套蒸汽循环，也不能免除损耗。

生产账本必须做到：

1. 反应功率由候选的粒子/能量状态和适用反应模型计算，不能复制 benchmark 目标功率或 LLM 预测。
2. 区分 α 自加热、可回收粒子/中子能量、辐射、输运及边界损失；不得把同一能量同时计为加热与额外发电收益。
3. 所有负载有 owner、单位、正负号、时间基准、来源、模型适用域和不确定性；未知保留 unknown，不能当零。
4. 周期包含启动、升温、稳态/脉冲、停机、复位与相应充电；储能期初/期末可比，不能以耗尽外部储能制造净输出。
5. 冻结工作窗口、 duty cycle、故障/停机、热和结构极限及燃料补给约束。D-T 的氚收支/增殖是适用义务；其他反应按物理适用性处理，不按家族名路由。
6. 正净输出必须在预登记的不确定性与模型差异评估下成立。事前选定有依据的保守下界为正，或明确概率模型下的分位数/失效概率门及其阈值；不得看结果后选择有利判据，本包不杜撰置信水平。只有有来源的概率模型才能给置信/可信区间；确定性 ±5% 端点只给条件范围，非统计置信度。
7. 输出守恒误差预算、独立重算与源结果哈希链。稳定性、工程或燃料硬门失败时，即使账面净电为正，也不得晋升。

完整闭合还必须覆盖反馈：压力/电流与平衡、n/T 与反应/自加热/输运、线圈/控制/温度与场及实现状态。凡有不可忽略反作用的适用块，应在同一候选和场景下联立求解或分区迭代到预登记的接口、状态与守恒容差。一次性单向后处理即使逐节点有真实输出，也不能算整机闭合；采用单向近似必须提供可忽略反作用的定量依据及误差预算。

## 5. 原创性不能由新 hash 证明

分别记录：表示非重复、数学非等价、结构/机制差异、独特可观察行为、外部先例审查。单纯换名称、对称变换、加冗余元件、改变随机种子或参数微扰不能算全新机制。

搜索器需要实际执行 G1/G2/G3 的有意义 typed edit；G1 新提议必须遵守维度、守恒、已知极限、可观测性和证据义务。允许提出待检验的机制组合，不允许为得到净能量任意编造不守恒方程。对于实质新物理假说，旧模型验证不能自动外推，必须另列证伪实验与待验证义务。

外部原创审查记录文献/专利检索词、来源、时间、相似装置、差异和独立复核。只能声称“在所审查范围内未发现等价先例”；这仍不足以宣称绝对历史首次、专利有效或已获实验确认。缺少外部审查时 R09 未过。

## 6. evidence 与最终晋升

旧 `screen_only` 类型、历史回放和 manufactured fixtures 保持原上限。新增科学证据合约及适用 stage 的 checker，绑定候选、场景、输入、方法、版本、数值设置、数据来源、不确定度、independence group 与原始产物。

给每个等级同时建立正、负通路：真实适用 benchmark 证据可被接纳；同源 replay、篡改、缺项、域外、跨候选以及 screen 伪装高等级必须拒绝。synthetic 正例可测试判定程序，但不能作为该等级物理证据。

L3 数值整机、L4 有工程与独立验证支撑的候选、L5 实物资格保持分离。L4 完成不允许写“已建造测得净电”。最终发现 Goal 完成至少要求一个新候选同时通过适用的全部 R03–R09，并完成 R01/R02 的能力基准及 R10 的独立重放；缺任何硬门都保持未完成。
