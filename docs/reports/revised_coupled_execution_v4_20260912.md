## 2. 实际计算得到了什么结果

### 完整声明残差的求解失败

从真实 HDF5 取 **17,920** 个样本：每区 6 点 Gauss 径向积分，16×16 角向节点，
5 个周期按实际 Cartesian 旋转展开。界面和外边界分别在精确 `rho=0.5,1` 求值，
没有用有限偏移替代极限。轴面为零面积、角方向周期，体源显式为零。

状态为 `x=(a_core,c_core,a_edge,c_edge)`，`B_i=a_i B_DESC`、`J_i=a_i J_DESC`、
`p_i=c_i q p_DESC`。应力 `T=BB'/mu0-(p+B²/(2mu0))I`，
弱式使用体项 `-∫T:∇v`、外边界和配对界面；边界规定参考 DESC 牵引力。
所有 36 行及 4 列 Jacobian 实际组装。守恒账本分别记录源、体、外边界、界面和强式诊断。

| 指标 | 实测值 |
|---|---|
| 初始状态 | `(1,1,1,1)` |
| 最终状态 | `(0.5,0.5,0.5944771568624893,0.5)` |
| 历史 | 6 条状态记录，5 次接受的实际更新 |
| scaled residual norm | `1.77223837459 → 1.02080259616` |
| 原始残差 L2 | `87,985.5349 → 18,489,788.2281 N`，恶化 **210.146 倍** |
| 停止原因 / exit | `bounded_line_search_failed` / **3** |
| 界面牵引跳跃峰值 | `297,184.0216 Pa` |
| 外边界牵引失配峰值 | `1,995,864.8848 Pa` |
| core / edge 强力密度 RMS | `8,838.0378 / 16,737.6894 N/m³` |

行尺度从 1 N 到约 55.98 MN；因此 scaled 指标下降可以伴随原始残差大幅恶化。
最终状态不是受限最优点：可行方向仍能降低目标，带裁剪的 Gauss–Newton 步停滞。
全局矢量积分因对称性接近零，不能推翻局部残差和边界缺陷；`conservation_certified=false`。

独立变换 `y=(a_core²,c_core,a_edge²,c_edge)` 的 SVD 给出无约束离散残差下限 `0.4611093161`，
但该状态违反候选系数范围。另一个只读审计枚举 81 个 box face，25 个可行子问题，
得到受限最优诊断 norm `0.9619104528`。实际结果相对无约束下限的平方差 `0.8294161389`
应拆成约束代价 `0.7126499180` 与算法差距 `0.1167662209`。
这些是诊断，没有替换实际执行状态或下游磁场。

### 工程、控制和故障的真实计算

精确外边界点 `theta=zeta=0` 的磁场，经最终 `a_edge` 缩放后，沿局部 `e_phi` 投影为
**0.8564838624 T**。线圈通过 Faraday 感应电动势接入 RL、读出积分和故障保护；
并未将等离子体压力或牵引力解释为实体结构应力。

场变化是明确的探索性场景：2 ms 内上升 10%，总时长 4 ms，步长 10 μs；
不是实测轨迹，也不是等离子体瞬态解。外域场延拓、有限线圈孔径和可安装性仍 unsupported。

| 指标 | 正常工况 | 1 ms 负载短路 |
|---|---:|---:|
| 实际步数 | 400 | 400 |
| 电流峰值 | 3.3065319 mA | 20.2805600 mA |
| 保护 | 不触发 | 1.54 ms 锁存，1.55 ms 切入 dump |
| 重建 ΔB | 0.0842001437 T | 0.0380446301 T |

正常工况的内部 `measurement_valid` 只表示理想读出连接和场景有效，不推翻总阶段 fail 或物理适用性限制。

### 数值核验与可执行传播

- 独立原始样本/标量应力实现重算 36 行残差；L2 差 `4.0178392e-8 N`，
  最大行尺度归一差 `5.0276391e-9`，超过冻结 `1e-10` 阈值，保持 **fail / exit 1**。
- 全 36×4 Jacobian 中央差分的矩阵相对误差 `2.4542383e-10`，通过矩阵 `1e-7` 判据。
  四列相对误差分别为 `1.8096e-10, 5.8872e-7, 1.2465e-10, 7.1700e-7`；
  **不能说每列均通过 1e-7**。70 位 Decimal 同原始 binary64 输入重归约后，
  四列解析系数差约 `8e-15`，支持压力列差分受大应力相消和小差分步长放大影响。
- 最严重近零残差行的绝对项和约 `1.3592e7 N`，production/独立双精度/70 位值分别约
  `6.975e-10/-4.330e-9/-3.047e-10 N`。这解释了严格判据下的 roundoff 失败；未放宽阈值。
- 独立强体积分与自然弱式的差 `4.6331987e-8 N`，属于积分、导数/metric 一致性和表达恒等式的组合诊断。
  纯积分误差估计 unsupported；空间加密/扩大状态与测试空间的求解尚未实现，不能称离散收敛。
- 正常 RL 的独立解析指数解验证覆盖整段轨迹；10 μs/5 μs 最大电流误差
  `5.9386292e-5/3.0295869e-5 A`，观测阶 **0.9710**。这只验证理想无保护 RL 的软件/时间离散。
- 实际执行线圈半径 `[4.5,5.5] mm`、电阻率 `[1.6,1.9]e-8 Ω·m`、负载 `[8,12] Ω` 的 8 个设计角点。
  峰值电流范围 **2.23840–4.97764 mA**，重建 ΔB 范围 **0.0834678–0.0846328 T**。
  来源为候选探索性设计规范；不是测量区间、全局包络、分布或置信区间。
- 实际执行压力乘子 `q=0.9,1.1` 的两个重新求解，再送入工程；两次物理均 exit 3，工程均 exit 0。
  固定 DESC 几何/参考 B 和规定外牵引力，不能解释为重新平衡后的 profile UQ。
  B 投影变化仅约 `3.57e-11 T` 与系数缩放冗余/求解停滞相关，不能当作物理鲁棒性。
