# DESC rho partition and oriented trace specification v4

This isolated structural screen binds the full accepted DESC basis request,
result, receipt, geometry/proof, execution, field, point, and sample identity
chain to an ordered, candidate-owned rho partition. It requires unique,
non-overlapping, gap-free region interiors whose closures cover rho zero through
rho one. The rho-zero axis is a declared excluded boundary, never a field or
trace sample. Each internal interface must be the sole ordered boundary between
adjacent regions.

The two trace views at an interface must reference the same exact basis sample.
The validator reconstructs that sample from the bound basis result and checks
rho/theta/zeta, position, Cartesian B and force-residual vectors, and sqrt(g)
without accepting caller-substituted values. The two views also carry declared
opposite unit Cartesian normals. This validates only the declaration's pairing;
it does not claim that DESC or a geometry provider computed those normals.

The contract is not a provider or solver result. It performs no interface-trace
execution and does not assert full 3-D spatial-partition geometry, normal
geometry, constitutive closure, convergence, physical validation, device
authority, evidence, promotion, P5, or terminal authority. Those fields remain
false and credible-device count remains zero. Screening requires the full
external basis request/result/receipt inputs; a merely self-consistent request
hash cannot enter the screen.
