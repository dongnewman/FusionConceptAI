## 数学对象与接口

本轮正式生产选择现有 partitioned composite evaluator；Duffy/GL8 已保存的 C771 下降保留原诊断范围。不得把两个数值中心直接换名互用。

R/Z 源场写成 `B_RZ = E(g) I(x)`。完整导数是 `E S + G C Pψ`，再加 PF/TF 的同一目标运动导数；其中 S 为实际 `(2879,69447)` 源电流 Jacobian，G 为固定源系数下包含目标与裁剪源边界运动的坐标导数，C 为实际 `(128,16641)` LCFS 坐标映射，Pψ 采用原保存的全局 ψ 列（当前为 `4:4:66564`）。16641 个节点不能替代2879个压力有效索引。每个局部 Q1 的 LL/LR/UL/UR 槽通过原 `q.columns` 接 S 行，不生成逐格稠密全状态矩阵。

源网格、SI 单位、作者线圈输入、Q1 槽顺序、状态/几何记录、裁剪分支、积分模板及分区规则须在同一数值问题上绑定。基线、试步和独立 h/h2 FD 使用同一 evaluator。裁剪拓扑、模板或可容许域越界必须报告 `typed_needs_rebuild`；不能悄悄换规则后宣称同算子 FD 合格。
