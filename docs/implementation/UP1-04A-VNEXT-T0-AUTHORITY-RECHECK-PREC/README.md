# UP1-04A-VNEXT-T0-AUTHORITY-RECHECK-PREC

This work order is an additive, typed-absent scaffold for the authority recheck gate after T0 and before T1. Sol accepts the local software scaffold as `accepted_limited` on independent postrun R3 `pass_limited`; the machine node remains `planned` / `proposal` / `review_pending` with `accepted=false`. It has no launcher and is not included by the shared FusionConceptAI entry point.

The only implementation scope is the seven files listed in `manifest.json`. The Julia source consumes T0 bundle bytes through an immutable snapshot, validates exactly one upstream authority record for each required layer `G1` and `G2`, and checks every legacy feedback target against the unique layer record. Multiple targets may share a layer, but their target key and target id must remain unique. Legacy authority equality is a contradiction check only; it never promotes a target or layer to authority.

Legacy status mapping is frozen as follows: `actual` → typed absence with `terminal_deferred` and `legacy_actual_without_declaration_authority`; `missing` → typed absence with `legacy_missing_authority`; `historical_absent` → typed absence with `legacy_historical_absent_authority`; `stale` and `contradictory` → fail closed; an unknown status → fail closed. Duplicate, missing, unknown, foreign candidate, layer mismatch, projection mismatch, and duplicate target conditions fail closed.

`VNextCheckedPresentAuthorityV1` is a sealed output type only. A checked-present result requires a fresh T0-owned declaration authority record carrying declaration reference, declaration hash, canonical bytes, source receipt, trusted attestation, and exact candidate provenance. Synthetic, ref-only, and fixture records are rejected. The current scaffold has no fresh T0-owned record and therefore emits only typed absence or fail-closed results. It cannot synthesize a declaration reference, hash, canonical bytes, or source receipt.

Every result retains the prior bundle bytes and SHA-256. Bundle hash mismatch and all negative paths leave that snapshot unchanged. The accepted scope is limited to this local typed-absent software contract and its evidence; it does not grant binding, feedback, control, T0 authority, T1, T2, provider, mesh, engineering, physical, search, or R-credit authority. The recheck still has no checked-present output from a fresh T0-owned declaration record; T1 may only proceed within a separately reviewed typed-absence/local-contract scope and receives no authority credit.
