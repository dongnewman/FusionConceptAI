可以把场—几何基因组定义成：

\[ \mathcal G_{\mathrm{FG}} = (\mathcal X,\Phi,\mathcal A,\mathcal Q,\mathcal B, \mathcal E,\Theta) \]

其中：

- \(\mathcal X\)：空间、坐标图与度量；
- \(\Phi\)：材料/区域隐式场；
- \(\mathcal A\)：势函数和物理场；
- \(\mathcal Q\)：外部源分布；
- \(\mathcal B\)：边界与接口算子；
- \(\mathcal E\)：几何演化和拓扑事件；
- \(\Theta\)：有界连续参数。

核心原则是：

> genome 保存连续场的生成程序；网格、曲面、导线、磁轴、磁岛和闭合区都是求解后的 phenotype。

## 1. 空间基因

首先声明场定义在哪里，但不预设装置名称：

```
SpatialSupportGene
├─ ambient_dimension
├─ chart_count
├─ chart_bounds[]
├─ periodic_axes[]
├─ metric_program
├─ coordinate_maps[]
├─ chart_transition_maps[]
└─ resolution_independent_scale
```

例如：

```
{
  "ambient_dimension": 3,
  "chart_count": 1,
  "chart_bounds": [[-4, 4], [-4, 4], [-4, 4]],
  "periodic_axes": [],
  "metric_program": {"opcode": "EUCLIDEAN_METRIC"},
  "reference_length_m": 1.0
}
```

复杂空间可由多个 chart 及其 transition map 描述，而不是强迫使用“环形”或“线性”标签。

## 2. 区域和材料如何编码

不直接生成：

```
plasma region
vacuum region
wall region
```

而是生成若干隐式相场：

\[ \phi_r(x,t) = b_r+ \sum_{j\in A_r} c_{rj}\, \psi_{\tau_j} \left(2^{\ell_j}R_jx-d_j\right) T_{m_j}(t). \]

每个活跃基函数项是一条基因：

```
ImplicitFieldTermGene
├─ field_ref
├─ basis_family
├─ level
├─ spatial_multi_index[]
├─ rotation_or_frame
├─ translation[]
├─ temporal_mode
├─ coefficient_gene
└─ unit_signature
```

可以使用：

- Fourier；
- B-spline；
- wavelet；
- radial basis；
- finite-element shape function；
- neural implicit field，但只能作为无晋级权表示层。

多区域归属由相场竞争产生：

\[ \chi_r(x,t) = \frac{\exp(\phi_r/\tau)} {\sum_k\exp(\phi_k/\tau)}. \]

或者在锐界面极限下：

\[ r(x,t)=\arg\max_k\phi_k(x,t). \]

因此：

- 区域不会重叠；
- 空间不会无故缺失；
- 界面由 \(\phi_i=\phi_j\) 自动产生；
- 区域数量、连通性、孔洞和分裂可以自然涌现。

一个 phase-field genome 可以写成：

```
{
  "field_id": "phi0",
  "field_role": "material_phase_logit",
  "basis_program": {
    "family": "adaptive_wavelet",
    "active_terms": [
      {"level": 1, "index": [0,0,0], "coefficient_gene": 0.42},
      {"level": 2, "index": [1,0,2], "coefficient_gene": -0.31}
    ]
  },
  "classification_role": "region_partition",
  "complexity_cost": 2
}
```

这里的 basis 是数值坐标系，不是装置组件。候选必须在 Fourier、wavelet 或网格加密后保持主要表型，才能证明结果不是某种 basis 的伪影。

## 3. 场源如何编码

不直接生成“第几号线圈”，而是生成连续电流、荷电、热、粒子和动量源。

### 磁场和电流

为了自动满足

\[ \nabla\cdot B=0, \]

不直接搜索 \(B\)，而是搜索矢势：

\[ B=\nabla\times A_B. \]

为了构造稳态无散电流，可以搜索电流势：

\[ J_{\rm ext} = \nabla\times\left(\chi_c A_J\right). \]

其中 \(\chi_c\) 是允许导电的材料相场。这样：

\[ \nabla\cdot J_{\rm ext}=0 \]

由表示方式保证，不需要靠惩罚函数近似满足。

```
PotentialFieldGene
├─ potential_id
├─ output_field_kind
├─ construction_operator
├─ support_phase_refs[]
├─ basis_terms[]
├─ gauge_condition
├─ amplitude_gene
├─ temporal_program
└─ source_budget_refs[]
```

例如：

```
{
  "potential_id": "aj0",
  "output_field_kind": "current_density",
  "construction_operator": "CURL_OF_PHASE_WEIGHTED_VECTOR_POTENTIAL",
  "support_phase_refs": ["phi_conductor"],
  "gauge_condition": "zero_mean_coulomb",
  "amplitude_gene": {
    "transform": "signed_log",
    "bounds": [-1e8, 1e8],
    "normalized_gene": 0.27
  }
}
```

后续求解器获得的是连续 \(J_{\rm ext}(x,t)\)。只有当这个场通过物理门后，realization 编译器才尝试把它离散成：

- 体电流分布；
- 表面电流势；
- 导线和线圈；
- 电极；
- 束流或其他实际源。

## 4. 其他源如何编码

粒子、热和动量源可统一表示：

\[ Q_a(x,t) = A_a\, g_a(\phi,x,t)\, \operatorname{softplus} \left( \sum_j c_{aj}\psi_j(x)T_j(t) \right). \]

`softplus` 用于必须非负的源；有正负方向的源使用 signed basis。

```
SourceFieldGene
├─ source_id
├─ account_kind
├─ target_state_ref
├─ support_predicate
├─ positivity_rule
├─ basis_program
├─ temporal_program
├─ total_budget
├─ unit_signature
└─ actuator_binding_status
```

总量通过积分约束归一：

\[ \int_\Omega Q_a\,dV \le Q_{a,\max}. \]

因此搜索不能通过增加更多 basis coefficient 凭空获得无限功率或粒子输入。

## 5. 边界基因如何编码

边界本身由相场零水平集产生：

\[ \Gamma_{ij} = \{x:\phi_i(x)=\phi_j(x)\}. \]

genome 编码的是界面上的物理算子：

\[ \mathcal B \left( z^-, z^+, n, \kappa, u \right)=0. \]

```
InterfaceOperatorGene
├─ interface_selector
├─ minus_phase_ref
├─ plus_phase_ref
├─ trace_input_refs[]
├─ operator_ast
├─ paired_conservation_accounts[]
├─ jump_conditions[]
├─ direction_rule
├─ validity_bounds
└─ failure_scope
```

例如：

```
normal particle flux continuity
tangential field jump from surface current
thermal contact resistance
sheath loss
radiation transmission/reflection
moving-interface force balance
```

这些仍然使用 typed operator AST，而不是字符串标签。

## 6. 动态几何如何编码

如果边界会运动，搜索的是相场演化律：

\[ \partial_t\phi + v_n|\nabla\phi| = D_\phi\nabla^2\phi - \frac{\partial V(\phi)}{\partial\phi}. \]

对应 genome：

```
GeometryEvolutionGene
├─ evolved_phase_ref
├─ normal_velocity_program
├─ curvature_term
├─ diffusion_or_regularization
├─ driving_state_refs[]
├─ event_triggers[]
└─ topology_change_permission
```

拓扑事件不直接写成“生成一个孔”或“分裂成两个区域”，而是由场演化产生，再由审计器检测：

- 连通分支数变化；
- Betti number 变化；
- 区域 birth/death；
- 接触、断裂或合并；
- 接口方向变化。

## 7. 哪些不能作为输入基因

下面这些应当是 phenotype，不应直接参与搜索：

- 磁轴位置；
- 闭合磁通面数量；
- 岛链数量；
- rotational transform；
- 分离面和 X-point；
- 场线逃逸时间；
- 区域体积；
- 曲率分布；
- genus/Betti number；
- 线圈数量；
- normal-field residual；
- equilibrium、stability、transport pass。

这些量必须由场求解、轨道追踪或拓扑分析计算。否则搜索器可以直接“声明自己有闭合磁面”。

## 8. Canonical genome

同一物理场可能有很多不同表示，必须消除表示冗余：

### 几何规范化

- 平移到质心；
- 主惯性轴定向；
- 统一长度尺度；
- phase label 规范排序；
- signed-distance reinitialization；
- 删除低于声明容差的 basis 项；
- 合并重复 basis 项。

### 场规范化

矢势有 gauge 等价：

\[ A\rightarrow A+\nabla\lambda. \]

因此可以：

- 固定 Coulomb gauge；
- 固定零均值；
- 或直接对物理 \(B\)、\(J\) 的采样/谱表示哈希，而不对原始 \(A\) 哈希。

### 分层哈希

```
spatial_support_hash
phase_partition_program_hash
source_program_hash
interface_program_hash
field_geometry_genome_hash
materialized_geometry_hash
field_solution_hash
emergent_topology_hash
realization_hash
mesh_and_evaluation_hash
```

其中 `field_geometry_genome_hash` 不包含网格分辨率；网格和 solver 设置进入 `evaluation_hash`。

## 9. 变异操作

场—几何 genome 使用结构化变异：

- 添加/删除一个局部 wavelet mode；
- 提升某个空间区域的 basis level；
- 分裂或合并 phase field；
- 改变相场之间的耦合；
- 添加一个无散电流势模态；
- 将静态源改为有界时变源；
- 添加界面动力学；
- 改变对称生成元；
- 添加一个新的 chart；
- 局部移动隐式边界；
- 将局域源转换为非局域响应源。

每次变异后必须重新执行：

- 单位检查；
- phase partition 完整性；
- 电荷连续性；
- \(\nabla\cdot B=0\)；
- 源功率和材料体积预算；
- 最小间距和曲率下界；
- 网格可解析性；
- 受影响的物理硬门。
