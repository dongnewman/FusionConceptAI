可以把机制基因组严格定义成一个“带类型、单位和守恒约束的可变长度算子程序”：

\[ \mathcal G=(S,I,O,E,\Theta,Y,U) \]

其中：

- \(S\)：状态基因；
- \(I\)：守恒/不变量基因；
- \(O\)：算子程序；
- \(E\)：算子依赖与耦合边；
- \(\Theta\)：连续参数；
- \(Y\)：可观测量；
- \(U\)：尚未闭合的假说算子。

它不是一条普通浮点向量；canonical genome 是一张 typed operator graph。需要给遗传算法使用时，再打包成整数 token、邻接表和连续参数向量。

## 1. 状态基因如何编码

每个状态变量使用固定记录：

```
StateGene
├─ state_id
├─ value_kind
├─ tensor_rank
├─ spatial_dimension
├─ time_kind
├─ unit_signature[7]
├─ lower_bound
├─ upper_bound
├─ parity_flags
├─ gauge_or_constraint_refs
└─ epistemic_state
```

例如：

```
{
  "state_id": "s0",
  "value_kind": "scalar_field",
  "tensor_rank": 0,
  "spatial_dimension": 3,
  "time_kind": "differential",
  "unit_signature": [0, -3, 0, 0, 0, 0, 0],
  "bounds": [1e12, 1e24],
  "parity_flags": ["even_under_time_reversal"]
}
```

`unit_signature` 使用七个 SI 基本单位的指数：

\[ [\mathrm{kg},\mathrm{m},\mathrm{s},\mathrm{A}, \mathrm{K},\mathrm{mol},\mathrm{cd}] \]

例如：

- 数密度 \(\mathrm{m}^{-3}\)：`[0,-3,0,0,0,0,0]`
- 能量密度 \(\mathrm{J/m^3}\)：`[1,-1,-2,0,0,0,0]`
- 磁场 T：`[1,0,-2,-1,0,0,0]`

单位不是描述性元数据，而是编译器执行算子组合合法性检查的类型。

## 2. 守恒基因如何编码

守恒基因不是“mass=true”这种标签，而是状态与源汇之间的稀疏账户：

```
InvariantGene
├─ invariant_id
├─ account_kind
├─ scope (typed)
├─ state_coefficients[]
├─ owned_ledger_occurrence_refs[]
├─ tolerance_log10
└─ entropy_direction
```

例如粒子账户：

```
{
  "invariant_id": "i0",
  "ledger_identity": {
    "account_kind_ref": {"id": "particle_number", "version": "v1"},
    "ontology_hash": {"value": "<64-hex-digest>"},
    "unit": {"exponents": [0, 0, 0, 0, 0, 0, 0]}
  },
  "scope": {"kind": "global"},
  "state_coefficients": [
    {"state_ref": "s0", "coefficient": [1, 1]}
  ],
  "owned_ledger_occurrence_refs": [
    {"operator_site_ref": "source0", "port_side": "output", "port_index": 1,
     "direction": "plus", "occurrence_kind": "occurrence_source_effect",
     "ledger_identity": {
       "account_kind_ref": {"id": "particle_number", "version": "v1"},
       "ontology_hash": {"value": "<64-hex-digest>"},
       "unit": {"exponents": [0, 0, 0, 0, 0, 0, 0]}
     }}
  ],
  "tolerance_log10": -8
}
```

`scope` 是封闭的 typed value，而不是可自由解释的字符串：`global` 不带目标；
`domain` 携带非空、去重并规范排序的 `state_refs`，只表示 G1 的状态分区；
`interface` 携带一个精确的 operator-site ref，并要求该 interface edge 声明同一完整守恒账户。
scope 的引用必须在当前 typed operator hypergraph 中精确闭合，失败时保留
`legacy_gene_semantics_unrepresentable`，不猜测旧版本的 ref 或 domain 语义。这里的 domain
不是 G2 场区域，也不宣称已经完成区域 ownership；G2 的几何/场边界仍由其自身 Genome 声明和验证。

每个 graph account effect 通过 MIMO 的精确 `program_position` 绑定到 endpoint node，
再规范化为 occurrence。公共 `ConservationLedgerOccurrenceRefV1` 只含
`operator_site_ref`、`port_side`、`port_index`、`direction`、`occurrence_kind` 和完整
`ledger_identity`；系数只存在于内部 normalized occurrence，不参与 occurrence owner key。
`port_index` 必须与该 edge 的 MIMO binding `program_position` 精确匹配，并由该 binding
解析到 endpoint node；不能仅按端口序号猜测图节点。
occurrence kind 由 typed edge role 派生：`occurrence_source_effect`、
`occurrence_sink_effect`、`occurrence_boundary_effect`、`occurrence_internal_effect`，以及
interface 的 `occurrence_interface_minus/plus`。系数用有理数 `[numerator, denominator]`，避免浮点误差改变 genome hash。

payload admission 要求每个 invariant 的声明 occurrence 集与其 scope/ledger 在图中推导出的
期望集双向相等，所有 invariant 的 ledger 集等于图中所有 occurrence 的 ledger 集，且每个
`(完整 ledger identity, 精确 typed scope)` owner 唯一；不同或重叠 scope 可以同时存在。

后续物理编译阶段仍需验证：

\[ \frac{d}{dt}I_k = \text{declared sources} -\text{declared sinks} -\text{boundary fluxes}. \]

该 structural ownership slice 只建立 occurrence 的 typed identity、scope 闭包和 owner
关系；它不实现、也不证明上述方程的数值守恒或 C0 物理拒绝。任何“内部算子凭空产生账户”
的判定必须由后续物理/编译阶段单独完成，不能从本 slice 的 ownership 结果推断。

## 3. 算子基因如何编码

每个物理表达式编码成 typed AST 节点。

```
OperatorGene
├─ opcode
├─ input_refs[]
├─ output_signature
├─ parameter_refs[]
├─ locality
├─ derivative_order
├─ causal_direction
├─ conservation_effect[]
├─ validity_bounds
└─ assembly_role
```

第一版可以定义约 30–50 个基础 opcode：

```
代数：
ADD, NEG, MUL, DIV, POW_RATIONAL, CONTRACT

时空：
DT, GRAD, DIV_OP, CURL, LAPLACE, MATERIAL_DERIVATIVE

通量：
ADVECT, DIFFUSE, ANISOTROPIC_FLUX

约束：
PROJECT_DIVERGENCE_FREE, ALGEBRAIC_CONSTRAINT

非局域：
INTEGRAL_KERNEL, CONVOLUTION, DELAY

动力学：
POISSON_BRACKET, RELAXATION, STOCHASTIC_DRIVE

事件：
THRESHOLD_SWITCH, DOMAIN_BIRTH, DOMAIN_DEATH

未知：
TYPED_OPERATOR_HOLE
```

一个守恒方程可以编码为：

```
o0 = DT(s0)
o1 = GRAD(s0)
o2 = APPLY_TENSOR(p0, o1)
o3 = ADVECT(s0, s1)
o4 = ADD(o3, NEG(o2))
o5 = DIV_OP(o4)
r0 = ADD(o0, o5, NEG(source0))
```

对应：

\[ \partial_t s_0+ \nabla\cdot \left(s_0s_1-\mathbf D\nabla s_0\right) -S_0=0. \]

算子节点同时保存输入和输出的单位、张量秩及空间维度。比如 `GRAD` 自动完成：

\[ \text{scalar}\,[u] \rightarrow \text{vector}\,[u\,\mathrm m^{-1}]. \]

因此不需要枚举所有可能公式；使用类型正确的程序组合生成公式。

## 4. governing、additive 和 constraint 基因

每个 residual block 必须声明角色：

```
{
  "residual_id": "r0",
  "row_state_ref": "s0",
  "root_operator_ref": "o5",
  "assembly_role": "governing"
}
```

规则是：

- 每个 differential/algebraic 状态恰好有一个 `governing` residual；
- 可以有任意数量的 `additive` residual；
- algebraic 状态必须对应 `constraint`；
- 接口通量必须成对出现、方向相反；
- mass matrix 和 Jacobian sparsity 由程序图推导。

这能直接编译到现有 v68 的 `StateBlockSpecV1`、residual block、Jacobian 和 mass matrix，而不是再写一个孤立求解器。[v68 编译约束](D:\\006-Programing\\LMC\\outputs\\fusion_concept_ai\\src\\candidate_residual_graph_runtime_v68.jl)

## 5. 连续参数如何进入 genome

所有物理参数保存三个东西：

```
ParameterGene
├─ transform
├─ physical_lower
├─ physical_upper
└─ normalized_gene
```

搜索变量统一为：

\[ g_i\in[-1,1]. \]

正数跨数量级参数使用对数映射：

\[ \theta_i= \exp\left[ \log\theta_{\min} +\frac{g_i+1}{2} \left(\log\theta_{\max}-\log\theta_{\min}\right) \right]. \]

普通有限参数使用线性映射。需要正负跨尺度时使用 signed-log。

这样：

- genome 中没有 `Inf`；
- 参数边界可哈希；
- 不同单位和数量级可以使用统一变异尺度；
- 参数变化不会改变 mechanism hash。

## 6. 对称性如何编码

不只保存 `"axisymmetric"` 名称，而保存作用生成元：

```
SymmetryGene
├─ coordinate_generator_matrix
├─ state_action_matrices[]
├─ group_order
├─ invariant_or_equivariant
└─ tolerance
```

例如离散旋转只需要：

- 坐标变换矩阵 \(R\)；
- 阶数 \(n\)；
- 约束 \(R^n=I\)；
- 各状态在 \(R\) 下如何变换。

这样可以生成螺旋、反射、复合离散对称性，而不是从装置类别表里选择。

## 7. 未知机制如何编码

允许 `TYPED_OPERATOR_HOLE`，但它不是任意空白：

```
{
  "opcode": "TYPED_OPERATOR_HOLE",
  "inputs": ["s0", "s1"],
  "output_signature": {
    "kind": "vector_field",
    "unit_signature": [0, -2, -1, 0, 0, 0, 0]
  },
  "allowed_conservation_effects": ["redistribute_only"],
  "forbidden_conservation_effects": ["net_energy_creation"],
  "maximum_ast_nodes": 12,
  "maximum_derivative_order": 2,
  "maximum_memory_length": 1,
  "null_model_ref": "u0_null",
  "alternative_model_refs": ["u0_alt1", "u0_alt2"],
  "observable_refs": ["y0", "y1"]
}
```

搜索器可以用符号回归、枚举、稀疏辨识或 learned operator 填这个 hole，但在候选绑定验证完成前只能保持 `unknown`。

## 8. 可观测量也必须是基因

原创机制如果没有独特可观测预测，无法与已有机制区分。

```
ObservableGene
├─ expression_root
├─ intervention_ref
├─ sampling_operator
├─ expected_effect_interval
├─ noise_model
├─ minimum_effect_size
└─ competing_prediction_refs
```

例如：

\[ y_0= \int_{\Omega} w(x)\,s_0(x,t)\,dx \]

并声明在某个干预 \(u(t)\) 下：

\[ \Delta y_0\in[0.15,0.30], \qquad \sigma_{\rm noise}+\sigma_{\rm numerical}<0.03. \]

如果候选提出的新算子与 null model 的预测差异低于噪声和数值误差，直接判为 `unidentifiable`，不进入正式机制档案。

## 9. Canonical genome 与多个哈希

同一个公式可能有不同写法，因此必须规范化：

- 状态 α-renaming；
- commutative operands 排序；
- 单位归一；
- 常数约分；
- 消除 `ADD(x,0)`、`MUL(x,1)`；
- 公共子表达式合并；
- operator DAG 图同构规范化；
- 参数转成无量纲 \(\Pi\) 群；
- realization 信息从机制身份中删除。

然后生成分层身份：

```
ontology_hash
operator_structure_hash
mechanism_hash
parameter_instance_hash
realization_hash
behavioral_signature_hash
```

`mechanism_hash`包含状态、守恒、operator DAG、对称性和可观测预测，但不包含：

- 装置名称；
- 线圈编号；
- 材料供应商；
- 具体参数值；
- 几何 realization。

这样相同机制的不同装置实现会归到一个机制等价类。

## 10. 遗传操作如何定义

不做普通 bit flip，而做保持类型的事务式变异：

- `add_state_with_governing_residual`
- `remove_unobserved_state`
- `split_state_by_timescale`
- `replace_operator_subtree`
- `local_to_nonlocal_flux`
- `add_feedback_path`
- `add_or_break_symmetry`
- `introduce_event_rule`
- `add_typed_operator_hole`
- `merge_equivalent_states`

交叉只允许在以下条件同时满足时交换子图：

- 输入输出单位相同；
- 张量秩相同；
- 守恒作用兼容；
- 因果方向兼容；
- residual ownership 不被破坏。

否则 crossover 无效，不使用自动“修好”来掩盖物理矛盾。

第一版不要立即做成无限递归语法，建议：

|基因对象|v1 范围|
|---|---|

|operator AST 节点|4–32|
|governing residual|等于状态数|
|additive residual|0–16|
|不变量/账户|1–6|
|连续参数|0–16|
|可观测量|1–8|
|typed operator hole|0–1|
|AST 最大深度|6|
|最高微分阶|2|
|非局域/记忆算子|各不超过 1|
|事件规则|0–2|

这已经不是现有组件的排列组合，而是数十亿到天文规模的合法物理程序空间。实际搜索不穷举，用 program synthesis、QD、Pareto 和 falsification-guided mutation 探索。

最核心的量化原则是：

> **基因保存“产生物理行为的最小程序”；区域、场线拓扑、组件和装置外形由求解及逆向 realization 产生。**
