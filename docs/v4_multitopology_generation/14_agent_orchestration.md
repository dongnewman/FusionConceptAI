## 责任与交付

| 角色 | 职责 | 交付 |
|---|---|---|
| 模块实现者 | 真实输入→状态/几何/DOF→物理律→R/J→原消费者，单位/错误处理一起完成 | 简短接口表、可应用修改、精确消费者、原验证命令 |
| consumer_qa | 与实现者分开，运行受影响短检与实际消费者，比较原A/B/资源/结果 | 实际命令/退出、覆盖范围、唯一失败及下一条件 |
| independent_review | 不承担实现或测试；检查遗漏、适用物理法、FD/oracle、结果范围 | GO/HOLD、理由与原证据指针 |
| environment_owner | 现有runner/资源采样/执行环境的具体失败 | 原位最小修复与受影响原测试；不扩新框架 |
| root | 共享入口唯一集成者、重计算唯一调度者、最终裁决 | 是否完整接线、是否具备原正式门信用 |

pressure、exterior/sheet、current/return按模块分工；源码准备并行但同一核心文件只有root写。实现者可提供patch，不能复制整套版本或在多个目录维护同名实现。例子在examples、样本在test/fixtures、入口在scripts；迁移核对引用。

短检检查消费者可达、字段/单位/维度/索引、一次真实R/线性步、改动J列FD和准备资源。失败须原因/修改收敛后长跑；已有合格证据按行为影响复用，无关文件变化不重跑整套。

最多9个同时角色和批次安排见21；硬件inverse替换已空闲lane。Julia/DESC/FreeGS重计算串行、UP2正式运行优先；常规小检查不得暗启重计算。数据缺口或新物理假设在编码前集中报决策，不能实现后默认填零。

保留原命令、退出、PID创建时间、资源、原始失败和必要结果hash；资源证明不足保持失败、零信用。交付只报告当前接口、实际结果、阻塞和下一条件；代码/文档/测试数量不表示项目完成度。

暂停执行由root调度落实：现有`agent_local_execution.py`预检只列技术依赖已满足项，不读取manifest的暂停字段，也不自动获恢复授权。本轮只做预检，不使用`--run`或派发数值工作；任何正式运行仍由root在用户恢复后启动。
